# Project Rules & Context

## Tech Stack & Architecture
- Next.js 16 pages router using TypeScript with src directory.
- Tailwind for styling.
- i18next and next-i18next for content internationalization with custom useTranslation hook at ./src/

## Coding Standards
- Always use functional components with explicit return types.
- Follow strict semantic HTML naming patterns.
- Follow Design style
- Performance is paramount

## Build and Verification
- Run `npm run buil` after completing any substantial file(s) modification to ensure the project builds successfully.
- Before starting a dev server always check if one is already running. if it is do no start a new one. If its not start one and terminate it after verifications
